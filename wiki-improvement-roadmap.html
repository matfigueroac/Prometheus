Wiki Improvement Roadmap

Objetivo

Elevar todo el vault desde índice útil + notas base hacia un sistema más detallado, navegable y reusable. La regla de mejora será simple: cada nota importante debe dejar de ser un placeholder y pasar a ser una referencia seria, con contexto, estructura, lectura crítica y enlaces útiles.

Criterio de calidad objetivo

Una nota madura del vault debería tener, cuando aplique:

  • frontmatter consistente
  • resumen breve pero preciso
  • qué contiene realmente
  • por qué importa
  • estructura temática o narrativa
  • lectura crítica
  • fuentes primarias / secundarias bien separadas
  • relacionadas y navegación clara

Fases de mejora

Fase 1 — navegación y placeholders críticos

Objetivo: cerrar los vacíos más notorios del vault para que el índice principal no apunte a notas demasiado pobres.

Prioridad alta:

  • cia-readingroom-record-273505
  • cia-readingroom-record-1693729
  • aaro-uap-workshop-2025
  • x-files
  • index

Resultado esperado:

  • placeholders convertidos en nodos útiles de triage
  • relaciones explícitas con notas ya maduras
  • prioridades visibles para seguir iterando

Fase 2 — paquete Stargate / CIA / remote viewing

Objetivo: consolidar la línea CIA-Stargate como uno de los ejes fuertes de X Files.

Prioridad alta:

  • gondola-wish
  • how-the-cia-spent-millions-on-psychic-spies-project-stargate-documentary-1
  • how-the-cia-spent-millions-on-psychic-spies-project-stargate-documentary-2
  • how-the-cia-spent-millions-on-psychic-spies-project-stargate-documentary-3
  • stargate-documentary-trilogy-index
  • cia-mars-exploration-1984

Resultado esperado:

  • línea temporal mínima
  • actores clave
  • claims fuertes vs débiles
  • separación entre documento auténtico, lore y evidencia

Fase 3 — paquete Marte X Files

Objetivo: ordenar Marte como subdominio propio dentro de X Files.

Prioridad alta:

  • mars-x-files-anomalies-vs-official-readings
  • mars-x-files-map
  • cydonia-martian-mystery-region
  • face-on-mars-official-image-reanalysis
  • ancient-water-on-mars-and-climate-loss
  • ancient-ocean-on-mars-evidence-vs-open-debate
  • mars-canals-schiaparelli-lowell-and-the-interpretive-error

Resultado esperado:

  • taxonomy evidencia fuerte / debatido / especulativo
  • tabla de anomalías famosas
  • enlaces cruzados entre ciencia, folklore y lectura visual

Fase 4 — Backrooms / liminal / internet lore

Objetivo: hacer que esta línea tenga profundidad equivalente a la de Marte y Stargate.

Prioridad alta:

  • backrooms-kane-pixels-timeline
  • backrooms-liminal-spaces-deep-dive

Resultado esperado:

  • cronología sólida
  • glosario mínimo
  • mapa de conceptos y estética
  • relación entre obra, comunidad y fenómeno cultural

Fase 5 — mantenimiento estructural del vault completo

Objetivo: endurecer el vault como sistema, no solo como colección de notas.

Prioridad alta:

  • dashboard
  • index
  • SCHEMA
  • log
  • workflow-uso-wiki

Resultado esperado:

  • navegación más clara
  • estados visibles (madura, en expansión, placeholder útil)
  • criterio único para futuras notas

Regla operativa

  • no crear notas nuevas si antes no se fortalecen las más importantes ya existentes
  • priorizar nodos muy enlazados o muy débiles
  • cada fase debe dejar al menos una mejora estructural y varias mejoras de contenido
  • cuando una fuente esté bloqueada, igual dejar una nota útil de triage y relación
