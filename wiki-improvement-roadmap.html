Wiki Improvement Roadmap

Aim

Elevate the entire vault from useful index + base notes to a more detailed, navigable and reusable system. The improvement rule will be simple: each important note must stop being a placeholder and become a serious reference, with context, structure, critical reading and useful links.

Objective quality criterion

A mature vault note should have, when applicable:

  • consistent frontmatter
  • brief but precise summary
  • what it actually contains
  • why it matters
  • thematic or narrative structure
  • critical reading
  • well separated primary/secondary sources
  • related and clear navigation

Improvement phases

Phase 1 — navigation and critical placeholders

Objective: close the most notable gaps in the vault so that the main index does not point to notes that are too poor.

High priority:

  • cia-readingroom-record-273505
  • cia-readingroom-record-1693729
  • aaro-uap-workshop-2025
  • x-files
  • index

Expected result:

  • placeholders converted into useful triage nodes
  • explicit relationships with already mature notes
  • visible priorities to continue iterating

Phase 2 — Stargate / CIA / remote viewing package

Objective: consolidate the CIA-Stargate line as one of the strong axes of X Files.

High priority:

  • gondola-wish
  • how-the-cia-spent-millions-on-psychic-spies-project-stargate-documentary-1
  • how-the-cia-spent-millions-on-psychic-spies-project-stargate-documentary-2
  • how-the-cia-spent-millions-on-psychic-spies-project-stargate-documentary-3
  • stargate-documentary-trilogy-index
  • cia-mars-exploration-1984

Expected result:

  • minimal timeline
  • key actors
  • strong vs weak claims
  • separation between authentic document, lore and evidence

Phase 3 — Mars X Files package

Objective: organize Mars as its own subdomain within X Files.

High priority:

  • mars-x-files-anomalies-vs-official-readings
  • mars-x-files-map
  • cydonia-martian-mystery-region
  • face-on-mars-official-image-reanalysis
  • ancient-water-on-mars-and-climate-loss
  • ancient-ocean-on-mars-evidence-vs-open-debate
  • mars-canals-schiaparelli-lowell-and-the-interpretive-error

Expected result:

  • taxonomy strong evidence / debated / speculative
  • famous anomalies table
  • cross-links between science, folklore and visual reading

Phase 4 — Backrooms / liminal / internet lore

Objective: make this line have depth equivalent to that of Mars and Stargate.

High priority:

  • backrooms-kane-pixels-timeline
  • backrooms-liminal-spaces-deep-dive

Expected result:

  • solid chronology
  • minimal glossary
  • map of concepts and aesthetics
  • relationship between work, community and cultural phenomenon

Phase 5 — Uncanny / Liminal category expansion

Objective: promote uncanny / liminal from a Backrooms subtopic into a major X Files interpretive category.

High priority:

  • uncanny-liminal-research-map
  • house-of-leaves-labyrinth-uncanny-architecture
  • backrooms-liminal-spaces-deep-dive
  • backrooms-kane-pixels-timeline

Expected result:

  • standalone category vocabulary
  • clear relationship between uncanny, liminality, nostalgia, hauntology and non-places
  • detailed literary anchor through House of Leaves
  • cross-links with Backrooms, analog horror, pseudo-archives and impossible architecture

Phase 6 — structural maintenance of the complete vault

Objective: harden the vault as a system, not just as a collection of notes.

High priority:

  • dashboard
  • index
  • SCHEMA
  • log
  • workflow-uso-wiki

Expected result:

  • clearer navigation
  • visible states (mature, expanding, useful placeholder)
  • sole criterion for future notes

Operating rule

  • Do not create new notes if the most important existing ones are not strengthened first.
  • prioritize very linked or very weak nodes
  • each phase must leave at least one structural improvement and several content improvements
  • When a source is blocked, still leave a helpful triage and relationship note

Current status

  • Active phase: Phase 5 — Uncanny / Liminal category expansion
  • Last strong upgrade completed: uncanny-liminal-research-map + house-of-leaves-labyrinth-uncanny-architecture
  • Next natural focus: official UFO/UAP + alternative archaeology
