Sacred Geometry and Recurring Symbol Systems

Purpose

This note tracks recurring symbol systems in the Ancient Civilizations lane without treating visual similarity as proof by itself.

The goal is to build a disciplined motif atlas: what appears, where it appears, when it appears, in what medium, and whether transmission is plausible.

Motifs currently tracked

| Motif | Appears in LaCroix lane as | Research risk |

|---|---|---|

| T-form / T-pillar | human form, temple body, axis, sacred geometry | Similar simple forms can arise independently |

| Step pyramid | ascent, levels of cosmos, initiatory hierarchy | Common architectural solution for mass/height |

| Inverted step pyramid | descent, underworld, mirrored cosmogram | Needs concrete artifact/site examples |

| Three-part doorway | body/mind/spirit or triadic initiation | Later esoteric overlay risk |

| Pine cone | knowledge transmission, pineal symbolism | High apophenia risk without local context |

| Handbag / bucket | transmission vessel, ritual tool | Must distinguish from actual buckets/baskets |

| Tree of life | life/order/cosmic axis | Very broad motif; needs culture-specific reading |

| Sun cross | solar cycle, sacred time | Common independent solar symbol |

| Seven rays/sages | planetary, chakra, wisdom lineages | Cross-cultural numerology risk |

| Griffin | guardian of time/sacred threshold | Needs iconographic control |

| Cup/grail | transmission of doctrine, initiation vessel | Later Christian/esoteric reinterpretation risk |

LaCroix / Stage of Time emphasis

LaCroix’s current public project emphasizes recurring T-form, step-pyramid and inverted step-pyramid geometry across sites such as Lake Van, Tiwanaku, Egypt and India. His website presents this as evidence of a missing ancient code or shared global design tradition.

This is useful for discovery, but the wiki should treat each comparison as a data row, not a conclusion.

Required metadata for every motif entry

Each motif comparison should include:

```text

Motif:

Site:

Culture:

Date range:

Object/medium:

Primary source / image:

Similarity rating:

Local conventional meaning:

Alternative interpretation:

Possible transmission route:

Independent invention likelihood:

Status:

```

Evidence filters

Stronger

  • same motif plus same function,
  • close chronology or plausible contact route,
  • inscriptions or texts explaining meaning,
  • archaeological context preserved,
  • multiple independent examples within a region.

Weaker

  • isolated visual similarity,
  • unclear date,
  • tourist-site claims without source,
  • later esoteric meaning projected backward,
  • symbol cropped out of original context.

Why this matters

A disciplined motif atlas can make the Ancient Civilizations wiki much stronger because it avoids the common failure mode of alternative-history content: collecting images that “look alike” without chronology, context or mechanism.

The aim is not to kill the pattern. The aim is to make the pattern testable.

Immediate build plan

1. Start with motifs explicitly mentioned in the Matthew LaCroix transcript.

2. Add Lake Van / Urartu examples.

3. Add Tiwanaku / Puma Punku examples.

4. Add Göbekli Tepe T-pillars separately because they are archaeologically important and much older than Urartu.

5. Add a comparison table with images later.
