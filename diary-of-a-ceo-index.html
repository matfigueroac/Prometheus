Purpose: staging folder for Diary Of A CEO episodes that touch X Files themes: ancient civilizations, alternative archaeology, consciousness, psychedelics, anomalous history, AI/religion and social epistemology.

Episodes ingested

  • graham-hancock-archaeology-warning-antarctica-lost-civilization-doac — Graham Hancock on Antarctica maps, ancient astronomy, Great Pyramid, Amazon discoveries, shamanism, science-as-authority and AI/machine-god framing.

Ingestion rule

For each new episode:

1. save YouTube metadata and best available timestamped transcript under raw/articles/diary-of-a-ceo/

2. create a structured note in this folder

3. extract only the X Files-relevant claims and timestamps

4. separate evidence, claim, critique and speculation

5. update this hub, x-files, index and log
