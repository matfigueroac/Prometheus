X Files

Área personal para temas que te interesan por curiosidad, rareza, estética o investigación informal.

Scope

  • teorías raras y conspirativas
  • CIA, documentos, inteligencia, remote viewing
  • UFO / UAP / fenómenos anómalos
  • liminal spaces, Backrooms, internet lore
  • mangas, ficción rara y universos extraños
  • cualquier info "loca" que valga la pena guardar

Criterio de calidad para esta área

Una nota de X Files no debería quedar como simple link o resumen corto. Idealmente debe incluir:

  • qué contiene realmente
  • por qué importa
  • lectura crítica
  • fuentes primarias y secundarias diferenciadas
  • enlaces a notas relacionadas para contraste
